# doodle talk

텍스트 붙여넣기 기반 대본 편집기. Next.js · React · TypeScript.

```sh
npm install
npm run dev
```

http://127.0.0.1:3000

## 기능
- `화자: 대사` 파싱 및 적용 전 미리보기, 최대 4명
- 대사 편집·순서 변경·추가·삭제, 화자 관리
- 표시 문장과 발화 문장 분리
- 말풍선 순차 미리보기 (음성 없음)
- 브라우저 localStorage 자동 저장, 내 작업 목록
- 대본 TXT 다운로드

화자 없는 후속 줄은 앞 대사에 이어 붙입니다. 첫 줄에 화자가 없으면 검수 표시합니다. 일반 콜론과 전각 콜론을 지원합니다.

브라우저 저장은 기기·브라우저별이며 사이트 데이터 삭제 시 사라집니다. 음성 합성·MP3·MP4·OCR·로그인·서버 저장은 아직 연결하지 않았습니다. 기존 캐릭터 원본 없이 설명을 기준으로 SVG 일러스트를 제작했습니다. Pretendard는 CDN에서 불러오며 오프라인에서는 시스템 글꼴로 표시됩니다.
